## Layout

Each book has its own folder under `books/`:

- `book.json`: title, subtitle, author, target dates, KDP details once known.
- `outline.md`: parts and chapters, with what each chapter draws on.
- `chapters/`: one Markdown file per chapter (`01-doing-the-work.md` and so on).
- `cover/`: cover source and final files.
- `build/`: Kindle and print files made from the chapters. Not edited by hand.

Shared scripts go in `tools/`.

## What stays out of this repo

- Interview notes and transcripts. They stay in the store (`r2antbooks`). Only what Ant agrees to print comes into a chapter.
- Charlie's real surname (she is Charlie Doll).
- Anything about Robyn beyond what Ant chooses to print.
- Ring 0 content, Forge client names or work detail, other people's private stories.
- Money figures, secrets and keys.
